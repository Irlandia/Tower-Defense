# Додавання контенту

1. Визнач тип: tower | enemy | wave | ability | modifier.
2. Додай запис у відповідний обʼєкт у `src/sim/data.js` за існуючою схемою (якщо поля не вистачає — це нова система, перейди на `/new-feature`).
3. Обов'язково для кожного: унікальний `id`, назва, опис для гравця (1 рядок), теги для синергій (`fire`, `wet`, `electric`, `armored`, `flying`...).
4. Вежа: має мати чітку роль і протидію; перевір, що не домінує над існуючими (спитай `critic`, якщо сумнівно).
5. Ворог: має вимагати від гравця зміни поведінки (броня, політ, розщеплення, лікування, стелс), не лише більше HP.
6. Спрайт — за `/pixel-art`. Тимчасово дозволено плейсхолдер-прямокутник кольору тегу.
7. Запусти баланс-бота (`/playtest`), щоб переконатись, що хвилі проходимі.
