# Мультиплеєр: правила

**Модель**: сервер авторитетний, тік 20 Гц. Клієнт шле команди `{type, tick, payload}`; сервер валідує, застосовує, розсилає стан (Colyseus schema patches). Клієнт інтерполює позиції ворогів між тіками.

**Детермінізм** (src/sim):
- лише seeded RNG з `src/sim/rng.js`; ніяких `Math.random`, `Date.now`, `performance.now`
- цілі числа або fixed-point для позицій/шкоди, де можливо
- стабільний порядок оновлення сутностей (за id)

**Валідація на сервері**: гроші, клітинка вільна і належить гравцеві, кулдауни, rate limit команд.

**Кімнати**: `solo` (локальна симуляція без сервера можлива), `coop` (2 гравці, спільне HP бази, окреме золото), `versus` (дві карти, `sendWave` купує ворогів суперникові + дає дохід).

**Чекліст перед мерджем**:
- [ ] тест детермінізму проходить (два прогони — однаковий хеш)
- [ ] невалідні команди відхиляються
- [ ] реконект протягом 30 с відновлює гравця
- [ ] вихід суперника у versus → перемога, у кооп → бот/продовження соло
- [ ] протестовано з штучним лагом 200 мс
