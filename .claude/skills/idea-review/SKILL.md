# Штурм ідей

1. Агент `innovator`: 8–10 ідей на тему з аргументу (наприклад «versus-взаємодія», «нові вороги», «чому середина гри нудна»).
2. Агент `critic`: вердикт кожній ідеї.
3. Склади таблицю: Ідея | Веселощі (1–5) | Складність S/M/L | Вердикт.
4. Запропонуй користувачу топ-3 для `/new-feature`. Нічого не реалізуй без його вибору.
