# Аватар гравця: «Шафа з дзеркалом»

> **Актуально (відкат дизайну):** садибу прибрано. Шафа — звичайна вкладка меню в старому вигляді (кнопка 👕 біля ніка); аватар показується в рейтингу (вкладка «Лідери») і в списку гравців кооп-кімнати. Решта документа описує початкову ідею, де двір і хата були частиною концепту.

> Нік — це ім'я, аватар — це обличчя. Гравець збирає свого героя в шафі в хаті, і далі його бачать на подвір'ї,
> біля вогнища, на Стіні слави й у кооп-друзів. Усе — лише зовнішній вигляд, жодної сили.
> Живий прототип редактора: `docs/prototypes/avatar.html` (http://td.local/docs/prototypes/avatar.html).

## 1. Принципи (вайб-фільтр з `vision.md` §2)
1. **Лише зовнішність.** Аватар не змінює гру, рейтинг, баланс і симуляцію (`VERSION` не чіпаємо).
2. **Швидко.** Створення — до 30 секунд із кнопкою «🎲 Випадково». Змінити можна будь-коли, безкоштовно, без підтверджень.
3. **Без вільного тексту й завантажень.** Тільки вибір з готових частин → нічого модерувати, нічого небезпечного.
4. **Без «чоловік/жінка».** Є форма тіла/зачіска/одяг як окремі незалежні вибори (у Stardew це теж окремі шари).
5. **Ніяких магазинів і валют.** Нові речі — це нагороди за історію гри (див. §6), а не за гроші.
6. **Читається в 7 пікселях.** Той самий герой — у 16×24 на портреті й у 7×11 на подвір'ї, і впізнається за кольорами.

## 2. Що бачить гравець

### 2.1 Перше знайомство (один раз)
Дід Панас питає: «А ти хто такий, {нік}? Ану покажись». Відкривається «Шафа з дзеркалом» одразу з випадковим
наміченим виглядом; кнопка «Подобається» зберігає. Пропустити не можна лише в тому сенсі, що вигляд уже обраний
випадково — ніхто не застрягає.

### 2.2 Шафа (у хаті)
- Нова річ у «Світлиці» — шафа з дзеркалом (праворуч від дверей) + хотспот «Шафа».
- Екран: ліворуч **дзеркало** (аватар ×8, повільно «дихає», махає при зміні), праворуч **вкладки-дошки** з варіантами.
- Категорії (V1): Зачіска · Колір волосся · Шкіра · Очі · Сорочка · Колір сорочки · Штани · Колір штанів · Убір · Додатки.
- Кожен варіант — мініатюра на всіх категоріях, ЛКМ — приміряти, одразу видно в дзеркалі й у «мініатюрі» (як тебе бачать на дворі).
- Кнопки: 🎲 Випадково · ↶ Назад · ✓ Зберегти. Дід коментує («О, тобі личить!»).
- Нижче дзеркала — прев'ю **твоєї рамки на Стіні слави**.

### 2.3 Де аватар живе далі
| Місце | Розмір | Що |
|---|---|---|
| Стіна слави («Захисники місяця») | 16×24 ×4–6, у золотій/срібній/бронзовій рамці | замість поточного безликого героя |
| Подвір'я | 7×11 | фігурка біля плота + у кооп-друзів біля вогнища |
| Вогнище (кооп) | 7×11 ×3 сидячи | з нікнеймом на дошці |
| Екран кінця забігу | 16×24 | радіє/сумує біля Діда |
| Бестіарій/Розшук | — | «фото» на плакаті **Тебе** (жарт: «Розшукується: {нік}» у кінці гри) |

## 3. Дизайн персонажа (арт-гейт A0)

**Стиль:** великоголовий «Stardew-подібний» чібі, 1-піксельний темний контур, м'які півтони, палітра Sweetie 16 + кілька
відтінків шкіри/волосся (як у фоні гри). Не копіюємо пропорції 1:1 — адаптуємо під наш масштаб і сільський тон.

**Сітка:** 16×24 (+контур = 18×26). Голова ~8×9, тулуб 8×8, ноги 3+3. Це «портрет». «Мініатюра» 7×11 будується з тих самих
вибраних кольорів за фіксованим шаблоном (як зараз `HERO` у `props.js`).

**Шари (знизу вгору):** тінь → ноги/взуття → тулуб+руки → шия → голова+вуха → очі/рум'янець/рот → волосся → додатки
(окуляри/вуса/хустина/квітка) → головний убір → контур.

**Каталог V1 (≈ 4 000 комбінацій, ~60 малюнків):**
| Частина | Варіанти |
|---|---|
| Зачіска (6) | коротка · кучері · коса · хвіст · козацький чуб · «горщик» |
| Колір волосся (8) | чорний · каштан · русявий · блонд · руде · сивина · блакитний · зелений (жартівливі) |
| Шкіра (6) | від світлої до темної |
| Очі (4) | чорні · сині · зелені · карі |
| Сорочка (4) | проста · **вишиванка** · жилет · светр |
| Колір одягу (10) | 10 кольорів палітри (на сорочку й штани окремо) |
| Штани (3) | штани · шаровари · спідниця |
| Убір (6) | без · солом'яний капелюх · кепка · **вінок** · вушанка · корона |
| Додатки (5) | немає · окуляри · вуса · хустина · квітка у волоссі |

**Анімації V1:** стоїть (дихання 2 кадри), махає рукою (3 кадри, у шафі), сидить (біля вогнища). Ходьба на подвір'ї — V2.

## 4. Дані й код

### 4.1 Формат
```
avatar = { hair, hairC, eyes, skin, shirt, shirtC, pants, pantsC, hat, acc }   // 10 малих цілих
code   = "0.1.0.1.1.8.0.6.0.0"                                                 // base36, ≤ 24 символи
```
- `parseAvatar(code)` завжди повертає валідний об'єкт (невідомі значення → за модулем/за замовчуванням).
- `avatarUnlocked(meta)` — **чиста функція**: з прогресу (рівень, місії, боси) виводить список відкритих частин; зберігати
  «відкрите» не треба.

### 4.2 Модулі
```
src/yard/avatar.js        # PARTS, paint(g, spec), sprite(spec) -> canvas 18×26, mini(spec) -> 7×11, parse/serialize, random, unlocked
src/client/ui/wardrobe.js # екран «Шафа»: дзеркало, вкладки, мініатюри, undo, random, save
src/yard/props.js         # heroCanvas() → використовує avatar.js (раніше — фіксований герой)
```
- `meta.avatar = { code, set: true }` (поле в `newMeta`, `load()` уже мерджить).
- Нова вкладка меню `wardrobe` (хотспот у хаті + кнопка в навігації як 7-ма).

### 4.3 Мережа (кооп) і сервер
- **Кооп:** `hello.avatar = code` (≤ 24 символи, `/^[0-9a-z.]{1,24}$/`), валідується в `protocol.js` та копіюється в
  `roster` (`{slot, nick, idx, avatar}`); гості бачать аватар одне одного на вогнищі й у забігу (рендер-only).
  Оновити `docs/net-protocol.md`. Сумісність: відсутній `avatar` = стандартний.
- **Таблиця лідерів:** `add_score` приймає `avatar` (валідація тим самим регулярним виразом); у `scores` рядки віддають
  `avatar`. Додатково `nicks` зберігає останній аватар для ніка (щоб старі записи теж «вдягнулись» після оновлення).
- **Симуляція:** не чіпається; аватар не потрапляє в `opts`, `VERSION` не змінюється, золотий реплей не страждає.

## 5. Інтеграція в наявний інтерфейс
- **Стіна слави:** `frameOf()` у `menu.js` замінює `heroCanvas(...)` на `sprite(parse(row.avatar))`; записи без аватара
  отримують детермінований випадковий вигляд за хешем ніка (виглядає живо, а не «порожньо»).
- **Двір:** фігурка біля плота береться з `meta.avatar` (7×11 мініатюра); партнери біля вогнища — з roster.
- **Вогнище:** `camp.js` вже малює сидячих героїв за `app.roster` → просто передати `avatar`.
- **Плакат «Розшукується: Ти»:** після поразки Дід жартує, показуючи твій портрет на дошці (екран кінця).

## 7. Ризики
| Ризик | Що робимо |
|---|---|
| **Арт — найбільша стаття витрат** (≈ 60 малюнків, 4 пози) | A0: 3 «ескізні» герої → арт-гейт власника; решту — палітрові свопи й шари |
| Читабельність 7×11 | мініатюра будується за шаблоном; тестуємо на 3 масштабах і на сезонних фонах |
| Гендерні стереотипи | немає «статі»; є незалежні частини; описи нейтральні |
| Накрутка/фальсифікація коду | регулярний вираз + clamp у `parse`; ніякого впливу на гру |
| Старі записи в таблиці без аватара | випадковий за хешем ніка |
| Розбіжність версій (нова частина в одного, немає в іншого) | невідоме значення → дефолт; частин не видаляємо |

## 9. Питання до власника
1. **Пропорції:** «чібі» з великою головою (як у прототипі) чи ближчі до Stardew (трохи вищі, менше голови)?
2. **Шаблон 7×11:** лишаємо наш мінімальний вигляд чи робимо двір на 10×16 (більше деталей, але виходимо за масштаб бою)?
3. **Рамка в рейтингу:** показувати аватар усім, чи дати перемикач «не показувати мене» (для приватності)?
4. **Корону/трофейні речі** робимо відразу чи після Трофейної стіни?
